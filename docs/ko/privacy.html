개인정보처리방침

최종 업데이트: 2026년 10월 11일

요약: WakeDeck은 개인정보를 수집, 공유, 판매하지 않으며 광고, 분석, 추적이 없습니다. 입력한 모든 내용은 휴대폰에 남습니다.

이 번역은 편의를 위해 제공됩니다. 영어 버전과 차이가 있으면 영어 버전이 우선합니다.

WakeDeck은 Diego Bergonsi가 만든 Android용 Wake-on-LAN 앱입니다. 이 방침은 앱이 데이터로 무엇을 하는지 설명합니다.

휴대폰에 남는 정보

WakeDeck에 입력한 모든 내용은 휴대폰에만 저장됩니다.

  • 추가한 기기: 이름, MAC 주소, IP 주소 또는 호스트 이름, 브로드캐스트 주소, 포트, 운영체제, 그룹, 그리고 선택 사항인 SSH 사용자 이름과 포트.
  • 위젯, 바로가기, 빠른 설정 타일의 설정.
  • 기기의 마지막으로 알려진 온라인 또는 오프라인 상태.
  • 선택 사항인 원격 종료 기능을 위한 SSH 키 쌍. 개인 키는 Android Keystore 안에서 만들어지며 그곳에서 읽거나 복사할 수 없습니다. 앱은 비밀번호를 묻거나 저장하지 않습니다. 또한 신뢰하기로 한 각 PC의 SSH 호스트 키 지문을 저장합니다.

이 중 어떤 것도 개발자나 개발자가 운영하는 서버로 전송되지 않습니다. WakeDeck에는 계정, 서버, 백엔드가 없습니다. 앱 데이터는 Android 클라우드 백업에서 제외됩니다.

네트워크 트래픽

WakeDeck은 사용자가 설정한 주소에만 연결합니다.

  • 기기에 설정한 브로드캐스트 주소로 보내는 Wake-on-LAN 매직 패킷(UDP).
  • 온라인 또는 오프라인 확인: 기기 호스트에 대한 TCP 연결 시도 또는 ping.
  • 원격 종료는 사용자가 탭하고 확인할 때만: 설정한 PC로의 SSH 연결.

이 트래픽은 휴대폰에서 사용자의 기기로 직접, 사용자의 Wi-Fi 또는 직접 운영하는 VPN을 통해 전달됩니다. 개발자를 거치지 않습니다.

직접 만드는 파일

내보내기 기능은 기기 목록을 사용자가 고른 파일에 씁니다. 이 파일에는 SSH 키나 신뢰한 호스트 키가 들어 있지 않습니다. WakeDeck은 파일을 어디에도 업로드하지 않습니다. 파일을 어떻게 쓸지는 사용자에게 달려 있습니다.

가져오기 기능은 사용자가 고른 파일을 읽습니다. 무언가를 추가하기 전에 WakeDeck은 파일 속 기기를 보여 주고, 집 네트워크 밖을 가리키는 기기가 있으면 경고합니다.

권한

  • 인터넷 및 네트워크 상태: 패킷을 보내고 기기 상태를 확인하기 위해.
  • Wake lock: 화면이 꺼진 상태에서 켜기 또는 상태 확인을 마치기 위해.
  • 알림: 런처 바로가기로 기기를 켠 뒤 앱이 짧은 확인 메시지를 표시할 수 있도록 시스템이 허용하는 용도로만 사용합니다. WakeDeck은 알림, 리마인더, 프로모션을 보내지 않습니다.

제3자

WakeDeck에는 데이터를 수집하는 광고, 분석, 충돌 보고 또는 기타 제3자 서비스가 없습니다. 휴대폰에서 실행되는 오픈 소스 라이브러리를 사용합니다.

후원

이 웹사이트의 후원 버튼은 자체 개인정보처리방침이 있는 제3자 사이트 Ko-fi를 엽니다. 앱에는 후원 기능이 없습니다. 모든 후원은 Ko-fi와 결제 서비스 제공업체가 처리하며, 개발자는 사용자가 남기기로 한 이름과 메시지처럼 Ko-fi가 보여 주는 정보만 볼 수 있습니다.

이 웹사이트

이 웹사이트는 쿠키, 분석, 스크립트를 사용하지 않으며 다른 사이트에서 아무것도 불러오지 않습니다. GitHub Pages에서 호스팅되고 도메인은 Cloudflare를 통해 관리됩니다. 다른 웹 호스트와 마찬가지로 각자의 개인정보처리방침에 따라 표준 서버 로그를 보관할 수 있습니다. 개발자는 그 데이터를 받거나 사용하지 않습니다.

어린이

WakeDeck은 어린이를 대상으로 하지 않으며 누구에게서도 데이터를 수집하지 않습니다.

변경
