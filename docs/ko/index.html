스마트폰으로 기기를 켜세요

WakeDeck은 직접 디자인한 위젯에서 바로 Wake-on-LAN 매직 패킷을 보내 PC를 켭니다. 홈 화면에서 한 번 탭하면 앱은 열리지도 않습니다.

Google Play 스토어: 출시 예정 후원하기

Android 8.0 이상에서 무료. 광고도, 분석도, 계정도 없습니다.

위젯을 중심으로 만들었습니다

홈 화면이 곧 리모컨입니다. 모양과 위치를 직접 정하세요.

직접 디자인하는 위젯

기기 하나, 목록, 격자 중에서 고르세요. 색상, 투명도, 모서리 반경, 테두리, 아이콘, 글자 크기, 레이아웃을 정할 수 있습니다. 온라인·오프라인 상태는 백그라운드에서 갱신됩니다.

한 번 탭, 앱 열 필요 없음

위젯에서 바로 켜기를 탭하세요. 런처 바로가기와 빠른 설정 타일에서도 켤 수 있습니다.

켜진 기기를 한눈에

어떤 기기가 온라인인지 확인하세요. 버튼 하나로, 또는 목록을 아래로 당겨 모두 새로 고칩니다.

그룹과 모두 켜기

기기를 사무실, 실험실 같은 그룹으로 묶고 버튼 하나로 그룹 전체를 켜세요.

SSH 원격 종료

선택 사항입니다. WakeDeck은 Android Keystore에 보관된 키로 로그인합니다. 비밀번호를 묻거나 저장하지 않으며, PC마다 호스트 키를 고정합니다.

설계부터 사생활 보호

광고도, 분석도, 계정도 없습니다. 기기와 설정은 휴대폰에만 있고, 앱은 추가한 주소하고만 통신합니다.

세 단계

앱 안의 가이드가 Windows와 Linux용 PC 설정을 안내합니다.

  1. Wake-on-LAN 켜기

    PC의 BIOS 또는 UEFI와 네트워크 카드 설정에서 켜세요. 유선 이더넷이 가장 잘 작동합니다.

  2. 기기 추가

    이름과 MAC 주소를 입력하세요. 온라인 상태를 보려면 IP 주소도 추가하세요.

  3. 위젯 추가

    홈 화면을 길게 눌러 WakeDeck 위젯을 추가하고 원하는 대로 꾸미세요.

내 데이터는 내 것

WakeDeck에는 서버도 계정도 없습니다. 개인정보를 수집하거나 공유하지 않습니다. 짧은 개인정보처리방침에서 휴대폰에 무엇이 저장되는지 정확히 확인하세요.

개인정보처리방침

집 밖에 있나요?

직접 운영하는 VPN을 사용하고, 기기의 브로드캐스트 주소를 서브넷의 주소(예: 192.168.1.255)로 설정하세요. VPN과 공유기가 이를 전달해야 합니다. 앱 안의 도움말에 자세한 방법과 흔한 오류 메시지가 설명되어 있습니다.

WakeDeck 후원하기

WakeDeck은 무료이며 광고가 없습니다. 시간을 아껴 주었고 보태고 싶으시다면, 후원은 Play 스토어 수수료와 도메인 비용을 충당하는 데 도움이 됩니다.
