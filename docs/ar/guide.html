دليل الإعداد

دليل إعداد الحاسوب. يتطلب التشغيل الإعدادات الواردة في القسم 1. الإيقاف عن بُعد عبر SSH (القسم 2) اختياري.

1. Wake-on-LAN (إعدادات الحاسوب)

تُشغّل الحزمة السحرية حاسوبًا مطفأً أو في وضع السكون، لكن فقط إذا كانت بطاقة الشبكة لا تزال تتلقى الطاقة وتنتظر الحزم. استخدم كابل شبكة: نادرًا ما يعمل التشغيل عبر Wi-Fi.

Linux

في BIOS/UEFI فعّل Wake on LAN (تختلف التسميات: Wake on LAN أو Power On By PCI-E أو Resume by PCI-E). إذا وُجد خيار ErP أو EuP أو السكون العميق فعطّله، لأنه يقطع الطاقة عن بطاقة الشبكة.

اعثر على اسم واجهة الشبكة (مثل enp8s0):

ip -br link

تحقق من إعداد Wake-on. يجب أن يظهر g:

sudo ethtool <iface> | grep Wake-on

فعّله (يُعاد ضبطه عند إعادة التشغيل):

sudo ethtool -s <iface> wol g

للإبقاء عليه بعد إعادة التشغيل باستخدام NetworkManager (استبدل اسم الاتصال، راجع nmcli connection show):

sudo nmcli connection modify "<connection>" 802-3-ethernet.wake-on-lan magic

Windows

في BIOS/UEFI فعّل Wake on LAN (تختلف التسميات: Wake on LAN أو Power On By PCI-E أو Resume by PCI-E). إذا وُجد خيار ErP أو EuP أو السكون العميق فعطّله، لأنه يقطع الطاقة عن بطاقة الشبكة.

افتح إدارة الأجهزة، وانقر نقرًا مزدوجًا على محوّل الشبكة، ثم علامة التبويب إدارة الطاقة: حدد “السماح لهذا الجهاز بإيقاظ الكمبيوتر” و“السماح فقط لحزمة سحرية بإيقاظ الكمبيوتر”.

في النافذة نفسها، علامة التبويب خيارات متقدمة: اضبط “Wake on Magic Packet” على Enabled (إن كان مدرجًا).

عطّل بدء التشغيل السريع: لوحة التحكم → خيارات الطاقة → اختيار وظائف أزرار الطاقة → تغيير الإعدادات غير المتوفرة حاليًا → ألغِ تحديد “تشغيل بدء التشغيل السريع”. عند تفعيل بدء التشغيل السريع، كثيرًا ما يتجاهل الحاسوب الذي أُطفئ الحزمة السحرية.

macOS

افتح إعدادات النظام → البطارية (MacBook) أو الطاقة (Mac المكتبي) → خيارات، وفعّل “الإيقاظ للوصول إلى الشبكة”. يعمل التشغيل بأفضل شكل عبر Ethernet: على MacBook استخدم محوّل Ethernet بمنفذ USB-C أو Thunderbolt وأبقه موصولًا بالطاقة. كثيرًا ما يتجاهل جهاز Mac النائم على Wi-Fi الحزمة السحرية.

على Wi-Fi، عطّل أيضًا “عنوان Wi-Fi الخاص” لشبكتك (إعدادات النظام → Wi-Fi → التفاصيل)، وإلا سيحصل Mac على عنوان MAC مختلف. في القائمة أدناه، “Ethernet Address” هو عنوان MAC لكل منفذ.

في WakeDeck أضف الجهاز بعنوان MAC الخاص بالحاسوب. تجده هنا:

Linux

ip -br link

Windows

ipconfig /all

macOS

networksetup -listallhardwareports

عنوان البث: آخر عنوان في شبكتك، مثل 192.168.1.255 للشبكة 192.168.1.x (القيمة الافتراضية 255.255.255.255 تعمل أيضًا على الشبكة نفسها). المنفذ: 9.

2. الإيقاف عن بُعد عبر SSH (اختياري)

استبدل PASTE_KEY_LINE_FROM_APP بسطر المفتاح المعروض في شاشة مفتاح SSH في WakeDeck.

يسجّل التطبيق الدخول بمفتاحه الخاص، وليس بكلمة مرور. يحتاج الحاسوب إلى خادم SSH، ويجب إضافة المفتاح العام للتطبيق إليه. تحتوي الأوامر أدناه على مفتاحك بالفعل.

Linux

ثبّت خادم SSH وشغّله (مثال لـ Debian/Ubuntu):

sudo apt install openssh-server && sudo systemctl enable --now ssh

في Fedora وArch وSteamOS تُسمى الخدمة sshd بدلًا من ذلك:

sudo systemctl enable --now sshd

أضف مفتاح التطبيق إلى مستخدمك. يقصر هذا السطر المفتاح على أمر الإيقاف:

mkdir -p ~/.ssh && chmod 700 ~/.ssh && echo 'PASTE_KEY_LINE_FROM_APP' >> ~/.ssh/authorized_keys && chmod 600 ~/.ssh/authorized_keys

اسمح بإيقاف التشغيل دون كلمة مرور. شغّل هذا الأمر ثم أضف السطر الذي تحته (استبدل youruser وتحقق من المسار بالأمر: which shutdown):

sudo visudo -f /etc/sudoers.d/wakedeck
youruser ALL=(ALL) NOPASSWD: /usr/bin/shutdown

Windows

في PowerShell بصلاحيات المسؤول، ثبّت OpenSSH Server وشغّله:

Add-WindowsCapability -Online -Name OpenSSH.Server~~~~0.0.1.0; Start-Service sshd; Set-Service -Name sshd -StartupType Automatic

حساب المسؤول: أضف المفتاح وقيّد أذونات الملف (وإلا يتجاهل SSH الملف):

Add-Content -Force -Path "$env:ProgramData\ssh\administrators_authorized_keys" -Value 'PASTE_KEY_LINE_FROM_APP'
icacls.exe "$env:ProgramData\ssh\administrators_authorized_keys" /inheritance:r /grant "Administrators:F" /grant "SYSTEM:F"

أما الحساب العادي فضع سطر المفتاح في C:\Users\NAME\.ssh\authorized_keys.

إذا استمر الرفض: تحقق من أن جدار الحماية يسمح بمنفذ TCP رقم 22 (تضيف ميزة OpenSSH القاعدة عادةً)، وأن الحساب ليس حساب Microsoft Entra ID الذي لا يمكنه استخدام المفاتيح.

macOS

فعّل خادم SSH: إعدادات النظام → عام → المشاركة → تسجيل الدخول عن بُعد، واسمح لمستخدمك.

أضف مفتاح التطبيق إلى مستخدمك. يقصر هذا السطر المفتاح على أمر الإيقاف:

mkdir -p ~/.ssh && chmod 700 ~/.ssh && echo 'PASTE_KEY_LINE_FROM_APP' >> ~/.ssh/authorized_keys && chmod 600 ~/.ssh/authorized_keys

اسمح بإيقاف التشغيل دون كلمة مرور. شغّل هذا الأمر ثم أضف السطر الذي تحته (استبدل youruser):

sudo visudo -f /etc/sudoers.d/wakedeck
youruser ALL=(ALL) NOPASSWD: /sbin/shutdown

في شاشة تعديل الجهاز أدخل المضيف (IP أو الاسم) ومستخدم SSH (اسم حسابك على الحاسوب) والمنفذ (22). اضغط على إيقاف التشغيل الآن. في المرة الأولى تحقق من أن البصمة المعروضة تطابق بصمة الحاسوب، ثم اضغط على وثوق. بصمة الحاسوب:

Linux

ssh-keygen -lf /etc/ssh/ssh_host_ecdsa_key.pub

Windows

ssh-keygen -lf $env:ProgramData\ssh\ssh_host_ecdsa_key.pub

macOS

ssh-keygen -lf /etc/ssh/ssh_host_ecdsa_key.pub

“رفض الحاسوب مفتاح SSH”: المفتاح أو اسم المستخدم غير صحيح. “تعذّر الاتصال”: الحاسوب مطفأ، أو المضيف أو المنفذ أو جدار الحماية غير صحيح. “ردّ الحاسوب بخطأ”: في Linux أو macOS يكون السبب عادةً قاعدة sudoers. “تغيّر مفتاح SSH للحاسوب”: أُعيد تثبيت الحاسوب أو أُعيد إنشاء مفاتيح SSH الخاصة به؛ لا تثق بالمفتاح الجديد إلا إذا كنت تتوقع ذلك.

3. خارج المنزل (VPN)

من خارج شبكتك المنزلية تحتاج أولًا إلى طريقة للدخول إليها، مثل VPN من نوع WireGuard أو Tailscale. الحزمة السحرية بث عام، وكثير من شبكات VPN لا تمرّر البث. ضع عنوان البث لشبكتك (مثل 192.168.1.255) في الجهاز. إذا ظل التشغيل عن بُعد لا يعمل، فالحل المعتاد هو جهاز صغير يعمل دائمًا في المنزل يرسل الحزمة نيابةً عنك (راوتر يدعم Wake-on-LAN أو Raspberry Pi). يعمل الإيقاف عن بُعد عبر SSH من خلال VPN ما دام عنوان الحاسوب قابلًا للوصول.

مشكلات التشغيل عن بُعد: “لا يوجد اتصال بالشبكة أو VPN” تعني أن الهاتف لا يملك مسارًا إلى ذلك العنوان، فاتصل بـ VPN أولًا. “لم يُعثر على عنوان البث” تعني أنه تعذّر تحليل الاسم أو العنوان المدخل في الجهاز. وقد تقبل VPN الحزمة دون أن تسلّمها: لا يستطيع التطبيق معرفة ذلك لأن الحزمة السحرية لا يأتي لها ردّ. تحقق من أن الحاسوب يعمل، وانظر إلى حالته في القائمة.
