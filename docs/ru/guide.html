Руководстве по настройке

Руководство по настройке компьютера. Для включения нужны настройки из раздела 1. Удалённое выключение по SSH (раздел 2) необязательно.

1. Wake-on-LAN (настройки компьютера)

Волшебный пакет включает выключенный компьютер или компьютер в спящем режиме, но только если сетевая карта по-прежнему получает питание и «слушает» сеть. Используйте сетевой кабель: по Wi-Fi включение редко работает.

Linux

В BIOS/UEFI включите Wake on LAN (названия отличаются: Wake on LAN, Power On By PCI-E, Resume by PCI-E). Если есть параметр ErP, EuP или глубокого сна, отключите его, так как он отключает питание сетевой карты.

Узнайте имя сетевого интерфейса (например, enp8s0):

ip -br link

Проверьте параметр Wake-on. Он должен показывать g:

sudo ethtool <iface> | grep Wake-on

Включите его (сбрасывается при перезагрузке):

sudo ethtool -s <iface> wol g

Чтобы сохранить настройку после перезагрузок с помощью NetworkManager (замените имя подключения, см. nmcli connection show):

sudo nmcli connection modify "<connection>" 802-3-ethernet.wake-on-lan magic

Windows

В BIOS/UEFI включите Wake on LAN (названия отличаются: Wake on LAN, Power On By PCI-E, Resume by PCI-E). Если есть параметр ErP, EuP или глубокого сна, отключите его, так как он отключает питание сетевой карты.

Откройте «Диспетчер устройств», дважды щёлкните сетевой адаптер, вкладка «Управление электропитанием»: отметьте «Разрешить этому устройству выводить компьютер из ждущего режима» и «Разрешить вывод компьютера из ждущего режима только волшебным пакетом».

В том же окне, вкладка «Дополнительно»: установите «Wake on Magic Packet» в значение «Включено» (если параметр есть).

Отключите быстрый запуск: Панель управления → Электропитание → Действие кнопок питания → Изменение параметров, которые сейчас недоступны → снимите флажок «Включить быстрый запуск». При включённом быстром запуске выключенный компьютер часто игнорирует волшебный пакет.

macOS

Откройте «Системные настройки» → «Аккумулятор» (MacBook) или «Экономия энергии» (настольный Mac) → «Параметры» и включите «Пробуждать для доступа к сети». Включение лучше всего работает по Ethernet: на MacBook используйте адаптер Ethernet для USB-C или Thunderbolt и держите его подключённым к питанию. Mac в спящем режиме по Wi-Fi часто игнорирует волшебный пакет.

При подключении по Wi-Fi также отключите «Частный адрес Wi-Fi» для вашей сети (Системные настройки → Wi-Fi → Подробнее), иначе у Mac будет другой MAC-адрес. В списке ниже «Ethernet Address» — это MAC-адрес каждого порта.

В WakeDeck добавьте устройство с MAC-адресом компьютера. Найти его можно здесь:

Linux

ip -br link

Windows

ipconfig /all

macOS

networksetup -listallhardwareports

Широковещательный адрес: последний адрес вашей сети, например 192.168.1.255 для 192.168.1.x (значение по умолчанию 255.255.255.255 тоже работает в той же сети). Порт: 9.

2. Удалённое выключение по SSH (необязательно)

Замените PASTE_KEY_LINE_FROM_APP строкой ключа с экрана «SSH-ключ» в WakeDeck.

Приложение входит со своим ключом, а не с паролем. На компьютере нужен SSH-сервер, и в него нужно добавить открытый ключ приложения. Команды ниже уже содержат ваш ключ.

Linux

Установите и запустите SSH-сервер (пример для Debian/Ubuntu):

sudo apt install openssh-server && sudo systemctl enable --now ssh

В Fedora, Arch и SteamOS служба называется sshd:

sudo systemctl enable --now sshd

Добавьте ключ приложения своему пользователю. Эта строка ограничивает ключ командой выключения:

mkdir -p ~/.ssh && chmod 700 ~/.ssh && echo 'PASTE_KEY_LINE_FROM_APP' >> ~/.ssh/authorized_keys && chmod 600 ~/.ssh/authorized_keys

Разрешите выключение без пароля. Выполните эту команду, затем добавьте строку под ней (замените youruser и проверьте путь командой: which shutdown):

sudo visudo -f /etc/sudoers.d/wakedeck
youruser ALL=(ALL) NOPASSWD: /usr/bin/shutdown

Windows

В PowerShell от имени администратора установите и запустите OpenSSH Server:

Add-WindowsCapability -Online -Name OpenSSH.Server~~~~0.0.1.0; Start-Service sshd; Set-Service -Name sshd -StartupType Automatic

Учётная запись администратора: добавьте ключ и ограничьте права на файл (иначе SSH его игнорирует):

Add-Content -Force -Path "$env:ProgramData\ssh\administrators_authorized_keys" -Value 'PASTE_KEY_LINE_FROM_APP'
icacls.exe "$env:ProgramData\ssh\administrators_authorized_keys" /inheritance:r /grant "Administrators:F" /grant "SYSTEM:F"

Для обычной учётной записи поместите строку с ключом в C:\Users\ИМЯ\.ssh\authorized_keys.

Если всё равно отказывает: проверьте, что брандмауэр разрешает TCP-порт 22 (компонент OpenSSH обычно добавляет правило) и что учётная запись не Microsoft Entra ID, такие учётные записи не могут использовать ключи.

macOS

Включите SSH-сервер: Системные настройки → Основные → Общий доступ → Удалённый вход, и разрешите доступ своему пользователю.

Добавьте ключ приложения своему пользователю. Эта строка ограничивает ключ командой выключения:

mkdir -p ~/.ssh && chmod 700 ~/.ssh && echo 'PASTE_KEY_LINE_FROM_APP' >> ~/.ssh/authorized_keys && chmod 600 ~/.ssh/authorized_keys

Разрешите выключение без пароля. Выполните эту команду, затем добавьте строку под ней (замените youruser):

sudo visudo -f /etc/sudoers.d/wakedeck
youruser ALL=(ALL) NOPASSWD: /sbin/shutdown

На экране изменения устройства укажите хост (IP или имя), пользователя SSH (имя вашей учётной записи на компьютере) и порт (22). Нажмите «Выключить сейчас». При первом подключении проверьте, что показанный отпечаток совпадает с отпечатком компьютера, затем нажмите «Доверять». Отпечаток компьютера:

Linux

ssh-keygen -lf /etc/ssh/ssh_host_ecdsa_key.pub

Windows

ssh-keygen -lf $env:ProgramData\ssh\ssh_host_ecdsa_key.pub

macOS

ssh-keygen -lf /etc/ssh/ssh_host_ecdsa_key.pub

«Компьютер отклонил SSH-ключ»: неверный ключ или имя пользователя. «Не удалось подключиться»: компьютер выключен либо неверны хост, порт или брандмауэр. «Компьютер ответил ошибкой»: в Linux или macOS обычно дело в правиле sudoers. «SSH-ключ компьютера изменился»: компьютер переустановили или его SSH-ключи создали заново; доверяйте новому ключу, только если ожидали этого.

3. Вне дома (VPN)

Вне домашней сети сначала нужен способ в неё попасть, например VPN WireGuard или Tailscale. Волшебный пакет — это широковещательная рассылка, а многие VPN не пересылают такие пакеты. Укажите в устройстве широковещательный адрес вашей сети (например, 192.168.1.255). Если включение на расстоянии всё равно не работает, обычное решение — небольшое всегда включённое устройство дома, которое отправит пакет за вас (роутер с Wake-on-LAN или Raspberry Pi). Удалённое выключение по SSH работает через VPN, пока адрес компьютера доступен.

Проблемы при удалённой работе: «нет подключения к сети или VPN» означает, что у телефона нет маршрута к этому адресу, поэтому сначала подключите VPN. «Широковещательный адрес не найден» означает, что имя или адрес в устройстве не удаётся разрешить. VPN также может принять пакет и не доставить его: приложение не может это определить, потому что у волшебного пакета нет ответа. Проверьте, включается ли компьютер, и посмотрите его статус в списке.
