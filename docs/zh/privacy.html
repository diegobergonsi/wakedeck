隐私政策

最后更新：2026 年 10 月 11 日

简而言之：WakeDeck 不收集、不分享、不出售任何个人数据，没有广告、统计或跟踪。你输入的所有内容都只保存在你的手机上。

本译文仅供参考。如与英文版本有差异，以英文版本为准。

WakeDeck 是由 Diego Bergonsi 开发的 Android 版 Wake-on-LAN 应用。本政策说明应用如何处理你的数据。

保存在你手机上的内容

你在 WakeDeck 中输入的所有内容都只保存在你的手机上：

  • 你添加的设备：名称、MAC 地址、IP 地址或主机名、广播地址、端口、操作系统、分组，以及可选的 SSH 用户名和端口。
  • 你的小组件、快捷方式和快速设置磁贴的设置。
  • 设备最近一次已知的在线或离线状态。
  • 可选的远程关机功能所用的 SSH 密钥对。私钥在 Android Keystore 内创建，无法从中读取或复制。应用从不索取也不保存密码。应用还会保存你选择信任的每台电脑的 SSH 主机密钥指纹。

以上内容都不会发送给开发者，也不会发送到开发者运营的任何服务器。WakeDeck 没有账号、服务器或后端。应用数据不会参与 Android 云备份。

网络流量

WakeDeck 只会连接你配置的地址：

  • 向你为设备设置的广播地址发送 Wake-on-LAN 魔术包（UDP）。
  • 在线或离线检测：对设备主机发起 TCP 连接尝试或 ping。
  • 远程关机，仅在你点按并确认后进行：与你设置的电脑建立 SSH 连接。

这些流量直接从你的手机发往你自己的设备，经由你的 Wi-Fi 或你自己运行的 VPN，不会经过开发者。

你选择创建的文件

导出功能会把你的设备列表写入你选择的文件。该文件不包含你的 SSH 密钥或已信任的主机密钥。WakeDeck 不会上传该文件。如何处理该文件由你决定。

导入功能会读取你选择的文件。在添加任何内容之前，WakeDeck 会向你显示文件中的设备，并对指向家庭网络之外的设备发出警告。

权限

  • 互联网和网络状态：用于发送数据包和检测设备状态。
  • 唤醒锁：用于在屏幕关闭时完成唤醒或状态检测。
  • 通知：仅用于让系统允许应用在通过启动器快捷方式唤醒后显示简短的确认消息。WakeDeck 不会发送通知、提醒或推广信息。

第三方

WakeDeck 不含任何会收集数据的广告、统计、崩溃报告或其他第三方服务。它使用在你手机上运行的开源库。

捐赠

本网站上的捐赠按钮会打开 Ko-fi，这是一个有自己隐私政策的第三方网站。应用本身没有捐赠功能。任何捐赠均由 Ko-fi 及其支付服务商处理，开发者只能看到 Ko-fi 显示的信息，例如你选择提供的姓名和留言。

本网站

本网站不使用 Cookie、统计或脚本，也不从其他网站加载任何内容。网站托管在 GitHub Pages，域名通过 Cloudflare 管理。与任何网站托管方一样，它们可能依据各自的隐私政策保留标准服务器日志。开发者不会接收或使用这些数据。

儿童

WakeDeck 不面向儿童，也不收集任何人的数据。

变更

如本政策有变更，新版本将在此地址发布，并标注新的日期。
