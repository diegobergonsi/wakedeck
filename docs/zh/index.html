用手机唤醒你的设备

WakeDeck 通过 Wake-on-LAN 魔术包唤醒你的电脑，直接在你自己设计的小组件上操作。在主屏幕上轻点一下，连应用都不用打开。

Google Play 商店：即将上架 捐赠

适用于 Android 8.0 及更高版本，免费。无广告、无统计、无需账号。

围绕小组件而设计

主屏幕就是你的遥控器。自己决定它的外观和位置。

由你设计的小组件

单个设备、列表或网格。可选择颜色、透明度、圆角、边框、图标、文字大小和布局。在线和离线状态在后台自动更新。

轻点一下，无需打开应用

直接在小组件上点按“唤醒”。也可以通过启动器快捷方式和快速设置磁贴来唤醒。

随时掌握开机状态

查看哪些设备在线。用一个按钮或下拉列表即可全部刷新。

分组与全部唤醒

把设备放进分组，例如“办公室”或“实验室”，一个按钮即可唤醒整个分组。

通过 SSH 远程关机

可选功能。WakeDeck 使用保存在 Android Keystore 中的密钥登录，从不索取也不保存密码，并会固定每台电脑的主机密钥。

隐私优先

无广告、无统计、无需账号。你的设备和设置只保存在手机上，应用只会连接你添加的地址。

三个步骤

应用内的指南会带你完成电脑端的设置，支持 Windows 和 Linux。

  1. 开启 Wake-on-LAN

    在电脑的 BIOS 或 UEFI 以及网卡设置中启用。有线以太网效果最好。

  2. 添加你的设备

    输入名称和 MAC 地址。若想查看在线状态，请再添加 IP 地址。

  3. 添加小组件

    长按主屏幕，添加 WakeDeck 小组件，并按你的喜好设置样式。

你的数据归你所有

WakeDeck 没有服务器，也没有账号。它不会收集或分享个人数据。阅读简短的隐私政策，了解手机上究竟保存了什么。

隐私政策

不在家？

使用你自己的 VPN，并把设备的广播地址设为你所在子网的广播地址，例如 192.168.1.255。你的 VPN 和路由器必须转发该广播。应用内的帮助会说明详细步骤和常见错误信息。
