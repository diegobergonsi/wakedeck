Opsætningsguiden

Opsætningsguide til pc’en. Tænding kræver indstillingerne i afsnit 1. Fjernlukning via SSH (afsnit 2) er valgfri.

1. Wake-on-LAN (pc-indstillinger)

En magisk pakke vækker en pc, der er slukket eller i dvale, men kun hvis netværkskortet stadig får strøm og lytter. Brug et netværkskabel: Wi-Fi virker sjældent til opvågning.

Linux

Slå Wake on LAN til i BIOS/UEFI (navnene varierer: Wake on LAN, Power On By PCI-E, Resume by PCI-E). Hvis der er en ErP-, EuP- eller dyb dvale-indstilling, skal du slå den fra, fordi den afbryder strømmen til netværkskortet.

Find netværksgrænsefladens navn (for eksempel enp8s0):

ip -br link

Tjek Wake-on-indstillingen. Den skal vise g:

sudo ethtool <iface> | grep Wake-on

Slå den til (nulstilles ved genstart):

sudo ethtool -s <iface> wol g

Sådan beholder du den efter genstarter med NetworkManager (udskift forbindelsens navn, se nmcli connection show):

sudo nmcli connection modify "<connection>" 802-3-ethernet.wake-on-lan magic

Windows

Slå Wake on LAN til i BIOS/UEFI (navnene varierer: Wake on LAN, Power On By PCI-E, Resume by PCI-E). Hvis der er en ErP-, EuP- eller dyb dvale-indstilling, skal du slå den fra, fordi den afbryder strømmen til netværkskortet.

Åbn Enhedshåndtering, dobbeltklik på dit netværkskort, fanen Strømstyring: markér “Tillad, at denne enhed vækker computeren” og “Tillad kun, at en magisk pakke vækker computeren”.

I samme vindue, fanen Avanceret: sæt “Wake on Magic Packet” til Enabled (hvis den findes på listen).

Slå Hurtig start fra: Kontrolpanel → Strømstyring → Vælg, hvad afbryderknapperne skal gøre → Skift indstillinger, som ikke er tilgængelige i øjeblikket → fjern markeringen i “Aktivér hurtig start”. Når Hurtig start er slået til, ignorerer en pc, der er lukket ned, ofte den magiske pakke.

macOS

Åbn Systemindstillinger → Batteri (MacBook) eller Energi (stationær Mac) → Valg, og slå “Væk for netværksadgang” til. Opvågning virker bedst via Ethernet: på en MacBook bruger du en USB-C- eller Thunderbolt-Ethernet-adapter og lader den sidde i strøm. En sovende Mac på Wi-Fi ignorerer ofte den magiske pakke.

På Wi-Fi skal du også slå “Privat Wi-Fi-adresse” fra for dit netværk (Systemindstillinger → Wi-Fi → Detaljer), ellers får Mac’en en anden MAC-adresse. På listen nedenfor er “Ethernet Address” hver ports MAC-adresse.

Tilføj enheden i WakeDeck med pc’ens MAC-adresse. Du finder den her:

Linux

ip -br link

Windows

ipconfig /all

macOS

networksetup -listallhardwareports

Broadcast-adresse: netværkets sidste adresse, for eksempel 192.168.1.255 for 192.168.1.x (standardværdien 255.255.255.255 virker også på samme netværk). Port: 9.

2. Fjernlukning via SSH (valgfrit)

Erstat PASTE_KEY_LINE_FROM_APP med nøglelinjen, der vises på skærmen SSH-nøgle i WakeDeck.

Appen logger ind med sin egen nøgle, aldrig med en adgangskode. Pc’en skal have en SSH-server, og appens offentlige nøgle skal tilføjes til den. Kommandoerne nedenfor indeholder allerede din nøgle.

Linux

Installér og start SSH-serveren (eksemplet gælder Debian/Ubuntu):

sudo apt install openssh-server && sudo systemctl enable --now ssh

På Fedora, Arch eller SteamOS hedder tjenesten i stedet sshd:

sudo systemctl enable --now sshd

Tilføj appens nøgle til din bruger. Linjen begrænser nøglen til lukkekommandoen:

mkdir -p ~/.ssh && chmod 700 ~/.ssh && echo 'PASTE_KEY_LINE_FROM_APP' >> ~/.ssh/authorized_keys && chmod 600 ~/.ssh/authorized_keys

Tillad lukning uden adgangskode. Kør denne, og tilføj derefter linjen under den (udskift youruser, og tjek stien med: which shutdown):

sudo visudo -f /etc/sudoers.d/wakedeck
youruser ALL=(ALL) NOPASSWD: /usr/bin/shutdown

Windows

Installér og start OpenSSH Server i PowerShell som administrator:

Add-WindowsCapability -Online -Name OpenSSH.Server~~~~0.0.1.0; Start-Service sshd; Set-Service -Name sshd -StartupType Automatic

Administratorkonto: tilføj nøglen, og lås filens tilladelser (ellers ignorerer SSH filen):

Add-Content -Force -Path "$env:ProgramData\ssh\administrators_authorized_keys" -Value 'PASTE_KEY_LINE_FROM_APP'
icacls.exe "$env:ProgramData\ssh\administrators_authorized_keys" /inheritance:r /grant "Administrators:F" /grant "SYSTEM:F"

På en almindelig konto lægger du i stedet nøglelinjen i C:\Users\NAVN\.ssh\authorized_keys.

Hvis den stadig afviser: tjek, at firewallen tillader TCP-port 22 (OpenSSH-funktionen tilføjer normalt reglen), og at kontoen ikke er en Microsoft Entra ID-konto, som ikke kan bruge nøgler.

macOS

Slå SSH-serveren til: Systemindstillinger → Generelt → Deling → Fjernlogin, og tillad din bruger.

Tilføj appens nøgle til din bruger. Linjen begrænser nøglen til lukkekommandoen:

mkdir -p ~/.ssh && chmod 700 ~/.ssh && echo 'PASTE_KEY_LINE_FROM_APP' >> ~/.ssh/authorized_keys && chmod 600 ~/.ssh/authorized_keys

Tillad lukning uden adgangskode. Kør denne, og tilføj derefter linjen under den (udskift youruser):

sudo visudo -f /etc/sudoers.d/wakedeck
youruser ALL=(ALL) NOPASSWD: /sbin/shutdown

På enhedens redigeringsskærm udfylder du vært (IP eller navn), SSH-bruger (dit kontonavn på pc’en) og port (22). Tryk på Sluk nu. Første gang skal du tjekke, at det viste fingeraftryk svarer til pc’ens, og derefter trykke på Stol på. Pc’ens fingeraftryk:

Linux

ssh-keygen -lf /etc/ssh/ssh_host_ecdsa_key.pub

Windows

ssh-keygen -lf $env:ProgramData\ssh\ssh_host_ecdsa_key.pub

macOS

ssh-keygen -lf /etc/ssh/ssh_host_ecdsa_key.pub

“Pc’en afviste SSH-nøglen”: forkert nøgle eller brugernavn. “Kunne ikke oprette forbindelse”: pc’en er slukket, eller vært, port eller firewall er forkert. “Pc’en svarede med en fejl”: på Linux eller macOS er det som regel sudoers-reglen. “Pc’ens SSH-nøgle er ændret”: pc’en er blevet geninstalleret, eller dens SSH-nøgler er genskabt; stol kun på den nye nøgle, hvis du forventede det.

3. Væk hjemmefra (VPN)

Uden for dit hjemmenetværk skal du først have en vej ind, for eksempel et WireGuard- eller Tailscale-VPN. En magisk pakke er en broadcast, og mange VPN’er videresender ikke broadcasts. Angiv dit netværks broadcast-adresse (for eksempel 192.168.1.255) i enheden. Virker opvågning på afstand stadig ikke, er den sædvanlige løsning en lille enhed, der altid er tændt derhjemme og sender pakken for dig (en router med Wake-on-LAN eller en Raspberry Pi). Fjernlukning via SSH virker over et VPN, så længe pc’ens adresse kan nås.

Problemer på afstand: “ingen netværks- eller VPN-forbindelse” betyder, at telefonen ikke har nogen rute til adressen, så opret først forbindelse til VPN. “Broadcast-adressen blev ikke fundet” betyder, at navnet eller adressen i enheden ikke kan slås op. Et VPN kan også modtage pakken uden nogensinde at levere den: appen kan ikke se det, fordi en magisk pakke ikke har noget svar. Tjek, om pc’en tænder, og se dens status på listen.
