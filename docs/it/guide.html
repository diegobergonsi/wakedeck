Guida alla configurazione

Guida alla configurazione del PC. Per l’accensione servono le impostazioni della sezione 1. Lo spegnimento remoto via SSH (sezione 2) è facoltativo.

1. Wake-on-LAN (impostazioni del PC)

Un pacchetto magico accende un PC spento o in sospensione, ma solo se la sua scheda di rete è ancora alimentata e in ascolto. Usa un cavo di rete: il Wi-Fi raramente funziona per l’accensione.

Linux

Nel BIOS/UEFI attiva Wake on LAN (i nomi variano: Wake on LAN, Power On By PCI-E, Resume by PCI-E). Se esiste un’opzione ErP, EuP o deep sleep, disattivala, perché toglie l’alimentazione alla scheda di rete.

Trova il nome dell’interfaccia di rete (ad esempio enp8s0):

ip -br link

Controlla l’impostazione Wake-on. Deve mostrare g:

sudo ethtool <iface> | grep Wake-on

Attivala (si azzera al riavvio):

sudo ethtool -s <iface> wol g

Per mantenerla dopo i riavvii con NetworkManager (sostituisci il nome della connessione, vedi nmcli connection show):

sudo nmcli connection modify "<connection>" 802-3-ethernet.wake-on-lan magic

Windows

Nel BIOS/UEFI attiva Wake on LAN (i nomi variano: Wake on LAN, Power On By PCI-E, Resume by PCI-E). Se esiste un’opzione ErP, EuP o deep sleep, disattivala, perché toglie l’alimentazione alla scheda di rete.

Apri Gestione dispositivi, fai doppio clic sulla scheda di rete, scheda Risparmio energia: seleziona “Consenti al dispositivo di riattivare il computer” e “Consenti solo a un pacchetto magico di riattivare il computer”.

Nella stessa finestra, scheda Avanzate: imposta “Wake on Magic Packet” su Abilitato (se è presente).

Disattiva l’avvio rapido: Pannello di controllo → Opzioni risparmio energia → Specifica comportamento pulsanti di alimentazione → Modifica impostazioni attualmente non disponibili → deseleziona “Attiva avvio rapido”. Con l’avvio rapido attivo, un PC spento ignora spesso il pacchetto magico.

macOS

Apri Impostazioni di Sistema → Batteria (MacBook) o Risparmio energia (Mac desktop) → Opzioni e attiva “Riattiva per l’accesso alla rete”. L’accensione funziona meglio via Ethernet: su un MacBook usa un adattatore Ethernet USB-C o Thunderbolt e tienilo collegato all’alimentazione. Un Mac in stop su Wi-Fi spesso ignora il pacchetto magico.

Con il Wi-Fi, disattiva anche “Indirizzo Wi-Fi privato” per la tua rete (Impostazioni di Sistema → Wi-Fi → Dettagli), altrimenti il Mac ottiene un indirizzo MAC diverso. Nell’elenco qui sotto, “Ethernet Address” è l’indirizzo MAC di ogni porta.

In WakeDeck aggiungi il dispositivo con l’indirizzo MAC del PC. Lo trovi qui:

Linux

ip -br link

Windows

ipconfig /all

macOS

networksetup -listallhardwareports

Indirizzo di broadcast: l’ultimo indirizzo della tua rete, ad esempio 192.168.1.255 per 192.168.1.x (anche il valore predefinito 255.255.255.255 funziona sulla stessa rete). Porta: 9.

2. Spegnimento remoto via SSH (facoltativo)

Sostituisci PASTE_KEY_LINE_FROM_APP con la riga della chiave mostrata nella schermata Chiave SSH di WakeDeck.

L’app accede con una chiave propria, mai con una password. Il PC ha bisogno di un server SSH e la chiave pubblica dell’app deve esservi aggiunta. I comandi qui sotto contengono già la tua chiave.

Linux

Installa e avvia il server SSH (esempio per Debian/Ubuntu):

sudo apt install openssh-server && sudo systemctl enable --now ssh

Su Fedora, Arch o SteamOS il servizio si chiama invece sshd:

sudo systemctl enable --now sshd

Aggiungi la chiave dell’app al tuo utente. La riga limita la chiave al comando di spegnimento:

mkdir -p ~/.ssh && chmod 700 ~/.ssh && echo 'PASTE_KEY_LINE_FROM_APP' >> ~/.ssh/authorized_keys && chmod 600 ~/.ssh/authorized_keys

Consenti lo spegnimento senza password. Esegui questo comando, poi aggiungi la riga sotto (sostituisci youruser e controlla il percorso con: which shutdown):

sudo visudo -f /etc/sudoers.d/wakedeck
youruser ALL=(ALL) NOPASSWD: /usr/bin/shutdown

Windows

In PowerShell come amministratore, installa e avvia OpenSSH Server:

Add-WindowsCapability -Online -Name OpenSSH.Server~~~~0.0.1.0; Start-Service sshd; Set-Service -Name sshd -StartupType Automatic

Account amministratore: aggiungi la chiave e limita i permessi del file (altrimenti SSH lo ignora):

Add-Content -Force -Path "$env:ProgramData\ssh\administrators_authorized_keys" -Value 'PASTE_KEY_LINE_FROM_APP'
icacls.exe "$env:ProgramData\ssh\administrators_authorized_keys" /inheritance:r /grant "Administrators:F" /grant "SYSTEM:F"

Con un account normale, invece, inserisci la riga della chiave in C:\Users\NOME\.ssh\authorized_keys.

Se continua a rifiutare: controlla che il firewall consenta la porta TCP 22 (la funzionalità OpenSSH di solito aggiunge la regola) e che l’account non sia un account Microsoft Entra ID, che non può usare le chiavi.

macOS

Attiva il server SSH: Impostazioni di Sistema → Generali → Condivisione → Login remoto, e consenti il tuo utente.

Aggiungi la chiave dell’app al tuo utente. La riga limita la chiave al comando di spegnimento:

mkdir -p ~/.ssh && chmod 700 ~/.ssh && echo 'PASTE_KEY_LINE_FROM_APP' >> ~/.ssh/authorized_keys && chmod 600 ~/.ssh/authorized_keys

Consenti lo spegnimento senza password. Esegui questo comando, poi aggiungi la riga sotto (sostituisci youruser):

sudo visudo -f /etc/sudoers.d/wakedeck
youruser ALL=(ALL) NOPASSWD: /sbin/shutdown

Nella schermata di modifica del dispositivo inserisci l’host (IP o nome), l’utente SSH (il nome del tuo account sul PC) e la porta (22). Tocca Spegni ora. La prima volta, controlla che l’impronta mostrata corrisponda a quella del PC, poi tocca Considera attendibile. L’impronta del PC:

Linux

ssh-keygen -lf /etc/ssh/ssh_host_ecdsa_key.pub

Windows

ssh-keygen -lf $env:ProgramData\ssh\ssh_host_ecdsa_key.pub

macOS

ssh-keygen -lf /etc/ssh/ssh_host_ecdsa_key.pub

“Il PC ha rifiutato la chiave SSH”: chiave o nome utente sbagliati. “Impossibile connettersi”: il PC è spento, oppure host, porta o firewall non sono corretti. “Il PC ha risposto con un errore”: su Linux o macOS di solito è la regola sudoers. “La chiave SSH del PC è cambiata”: il PC è stato reinstallato o le sue chiavi SSH sono state rigenerate; considera attendibile la nuova chiave solo se te lo aspettavi.

3. Fuori casa (VPN)

Da fuori della tua rete domestica serve prima di tutto un modo per entrarci, ad esempio una VPN WireGuard o Tailscale. Un pacchetto magico è un broadcast e molte VPN non inoltrano i broadcast. Inserisci nel dispositivo l’indirizzo di broadcast della tua rete (ad esempio 192.168.1.255). Se l’accensione da remoto continua a non funzionare, la soluzione consueta è un piccolo dispositivo sempre acceso a casa che invia il pacchetto al posto tuo (un router con Wake-on-LAN o un Raspberry Pi). Lo spegnimento remoto via SSH funziona tramite VPN finché l’indirizzo del PC è raggiungibile.

Problemi da remoto: “nessuna connessione di rete o VPN” significa che il telefono non ha un percorso verso quell’indirizzo, quindi connetti prima la VPN. “Indirizzo di broadcast non trovato” significa che il nome o l’indirizzo nel dispositivo non può essere risolto. Una VPN può anche accettare il pacchetto senza mai consegnarlo: l’app non può saperlo, perché un pacchetto magico non ha risposta. Controlla che il PC si accenda e guarda il suo stato nell’elenco.
