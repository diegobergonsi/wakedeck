Asennusopas

Tietokoneen asennusopas. Herättäminen vaatii luvun 1 asetukset. Etäsammutus SSH:lla (luku 2) on valinnainen.

1. Wake-on-LAN (tietokoneen asetukset)

Taikapaketti herättää sammutetun tai lepotilassa olevan tietokoneen, mutta vain jos verkkokortti saa edelleen virtaa ja kuuntelee. Käytä verkkokaapelia: Wi-Fi toimii herättämiseen harvoin.

Linux

Ota Wake on LAN käyttöön BIOSissa/UEFIssa (nimet vaihtelevat: Wake on LAN, Power On By PCI-E, Resume by PCI-E). Jos löytyy ErP-, EuP- tai syväunitila-asetus, poista se käytöstä, koska se katkaisee verkkokortin virran.

Selvitä verkkoliitännän nimi (esimerkiksi enp8s0):

ip -br link

Tarkista Wake-on-asetus. Sen pitäisi näyttää g:

sudo ethtool <iface> | grep Wake-on

Ota se käyttöön (nollautuu uudelleenkäynnistyksessä):

sudo ethtool -s <iface> wol g

Näin se säilyy uudelleenkäynnistysten yli NetworkManagerilla (korvaa yhteyden nimi, katso nmcli connection show):

sudo nmcli connection modify "<connection>" 802-3-ethernet.wake-on-lan magic

Windows

Ota Wake on LAN käyttöön BIOSissa/UEFIssa (nimet vaihtelevat: Wake on LAN, Power On By PCI-E, Resume by PCI-E). Jos löytyy ErP-, EuP- tai syväunitila-asetus, poista se käytöstä, koska se katkaisee verkkokortin virran.

Avaa Laitehallinta, kaksoisnapsauta verkkokorttiasi, Virranhallinta-välilehti: valitse “Salli tämän laitteen herättää tietokone” ja “Salli vain taikapaketin herättää tietokone”.

Samassa ikkunassa, Lisäasetukset-välilehti: aseta “Wake on Magic Packet” arvoon Enabled (jos se on luettelossa).

Poista Pikakäynnistys käytöstä: Ohjauspaneeli → Virranhallinta-asetukset → Valitse virtapainikkeiden toiminta → Muuta asetuksia, jotka eivät ole tällä hetkellä käytettävissä → poista valinta kohdasta “Ota pikakäynnistys käyttöön”. Kun Pikakäynnistys on päällä, sammutettu tietokone ohittaa taikapaketin usein.

macOS

Avaa Järjestelmäasetukset → Akku (MacBook) tai Virransäästö (pöytä-Mac) → Valinnat ja ota käyttöön “Herätä verkkoyhteyttä varten”. Herättäminen toimii parhaiten Ethernetin kautta: MacBookilla käytä USB-C- tai Thunderbolt-Ethernet-sovitinta ja jätä se kiinni virtaan. Wi-Fi-yhteydellä nukkuva Mac ohittaa taikapaketin usein.

Wi-Fi-yhteydellä poista myös verkostasi käytöstä “Yksityinen Wi-Fi-osoite” (Järjestelmäasetukset → Wi-Fi → Tiedot), muuten Macin MAC-osoite on toinen. Alla olevassa luettelossa “Ethernet Address” on kunkin portin MAC-osoite.

Lisää laite WakeDeckiin tietokoneen MAC-osoitteella. Löydät sen täältä:

Linux

ip -br link

Windows

ipconfig /all

macOS

networksetup -listallhardwareports

Yleislähetysosoite: verkon viimeinen osoite, esimerkiksi 192.168.1.255 verkolle 192.168.1.x (oletusarvo 255.255.255.255 toimii myös samassa verkossa). Portti: 9.

2. Etäsammutus SSH:lla (valinnainen)

Korvaa PASTE_KEY_LINE_FROM_APP WakeDeckin SSH-avain-näkymässä näkyvällä avainrivillä.

Sovellus kirjautuu omalla avaimellaan, ei koskaan salasanalla. Tietokoneessa on oltava SSH-palvelin, ja sovelluksen julkinen avain on lisättävä sille. Alla olevat komennot sisältävät jo avaimesi.

Linux

Asenna ja käynnistä SSH-palvelin (esimerkki Debianille/Ubuntulle):

sudo apt install openssh-server && sudo systemctl enable --now ssh

Fedorassa, Archissa tai SteamOS:ssä palvelun nimi on sen sijaan sshd:

sudo systemctl enable --now sshd

Lisää sovelluksen avain käyttäjällesi. Rivi rajoittaa avaimen sammutuskomentoon:

mkdir -p ~/.ssh && chmod 700 ~/.ssh && echo 'PASTE_KEY_LINE_FROM_APP' >> ~/.ssh/authorized_keys && chmod 600 ~/.ssh/authorized_keys

Salli sammutus ilman salasanaa. Suorita tämä ja lisää sitten sen alla oleva rivi (korvaa youruser ja tarkista polku komennolla: which shutdown):

sudo visudo -f /etc/sudoers.d/wakedeck
youruser ALL=(ALL) NOPASSWD: /usr/bin/shutdown

Windows

Asenna ja käynnistä OpenSSH Server PowerShellissä järjestelmänvalvojana:

Add-WindowsCapability -Online -Name OpenSSH.Server~~~~0.0.1.0; Start-Service sshd; Set-Service -Name sshd -StartupType Automatic

Järjestelmänvalvojan tili: lisää avain ja lukitse tiedoston oikeudet (muuten SSH ohittaa tiedoston):

Add-Content -Force -Path "$env:ProgramData\ssh\administrators_authorized_keys" -Value 'PASTE_KEY_LINE_FROM_APP'
icacls.exe "$env:ProgramData\ssh\administrators_authorized_keys" /inheritance:r /grant "Administrators:F" /grant "SYSTEM:F"

Tavallisella tilillä aseta avainrivi sen sijaan tiedostoon C:\Users\NIMI\.ssh\authorized_keys.

Jos se silti hylkää: tarkista, että palomuuri sallii TCP-portin 22 (OpenSSH-ominaisuus lisää säännön yleensä) ja että tili ei ole Microsoft Entra ID -tili, joka ei voi käyttää avaimia.

macOS

Ota SSH-palvelin käyttöön: Järjestelmäasetukset → Yleiset → Jakaminen → Etäkirjautuminen ja salli käyttäjäsi.

Lisää sovelluksen avain käyttäjällesi. Rivi rajoittaa avaimen sammutuskomentoon:

mkdir -p ~/.ssh && chmod 700 ~/.ssh && echo 'PASTE_KEY_LINE_FROM_APP' >> ~/.ssh/authorized_keys && chmod 600 ~/.ssh/authorized_keys

Salli sammutus ilman salasanaa. Suorita tämä ja lisää sitten sen alla oleva rivi (korvaa youruser):

sudo visudo -f /etc/sudoers.d/wakedeck
youruser ALL=(ALL) NOPASSWD: /sbin/shutdown

Täytä laitteen muokkausnäkymässä isäntä (IP tai nimi), SSH-käyttäjä (tilisi nimi tietokoneella) ja portti (22). Napauta Sammuta nyt. Tarkista ensimmäisellä kerralla, että näytetty sormenjälki vastaa tietokoneen sormenjälkeä, ja napauta sitten Luota. Tietokoneen sormenjälki:

Linux

ssh-keygen -lf /etc/ssh/ssh_host_ecdsa_key.pub

Windows

ssh-keygen -lf $env:ProgramData\ssh\ssh_host_ecdsa_key.pub

macOS

ssh-keygen -lf /etc/ssh/ssh_host_ecdsa_key.pub

“Tietokone hylkäsi SSH-avaimen”: väärä avain tai käyttäjänimi. “Yhteyden muodostus epäonnistui”: tietokone on sammutettu tai isäntä, portti tai palomuuri on väärin. “Tietokone vastasi virheellä”: Linuxissa tai macOS:ssä syynä on yleensä sudoers-sääntö. “Tietokoneen SSH-avain on muuttunut”: tietokone on asennettu uudelleen tai sen SSH-avaimet on luotu uudelleen; luota uuteen avaimeen vain, jos odotit sitä.

3. Poissa kotoa (VPN)

Kotiverkon ulkopuolella tarvitset ensin reitin sisään, esimerkiksi WireGuard- tai Tailscale-VPN:n. Taikapaketti on yleislähetys, eivätkä monet VPN:t välitä yleislähetyksiä. Anna laitteelle verkkosi yleislähetysosoite (esimerkiksi 192.168.1.255). Jos herättäminen etäältä ei vieläkään toimi, tavallinen ratkaisu on pieni aina päällä oleva laite kotona, joka lähettää paketin puolestasi (reititin, jossa on Wake-on-LAN, tai Raspberry Pi). Etäsammutus SSH:lla toimii VPN:n kautta, kunhan tietokoneen osoite on tavoitettavissa.

Etäongelmat: “ei verkko- tai VPN-yhteyttä” tarkoittaa, ettei puhelimella ole reittiä osoitteeseen, joten yhdistä ensin VPN:ään. “Yleislähetysosoitetta ei löytynyt” tarkoittaa, että laitteen nimeä tai osoitetta ei voi selvittää. VPN voi myös ottaa paketin vastaan toimittamatta sitä perille: sovellus ei näe sitä, koska taikapaketilla ei ole vastausta. Tarkista, heräävätkö tietokone, ja katso sen tila luettelosta.
