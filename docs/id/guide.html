Panduan penyiapan

Panduan penyiapan PC. Untuk menyalakan diperlukan pengaturan di bagian 1. Mematikan jarak jauh lewat SSH (bagian 2) bersifat opsional.

1. Wake-on-LAN (pengaturan PC)

Paket ajaib membangunkan PC yang mati atau tidur, tetapi hanya jika kartu jaringannya masih mendapat daya dan mendengarkan. Gunakan kabel jaringan: Wi-Fi jarang berhasil untuk membangunkan.

Linux

Di BIOS/UEFI, aktifkan Wake on LAN (namanya bervariasi: Wake on LAN, Power On By PCI-E, Resume by PCI-E). Jika ada opsi ErP, EuP, atau deep sleep, matikan, karena opsi itu memutus daya kartu jaringan.

Cari nama antarmuka jaringan (misalnya enp8s0):

ip -br link

Periksa pengaturan Wake-on. Harus menampilkan g:

sudo ethtool <iface> | grep Wake-on

Aktifkan (akan kembali semula saat reboot):

sudo ethtool -s <iface> wol g

Agar tetap aktif setelah reboot dengan NetworkManager (ganti nama koneksi, lihat nmcli connection show):

sudo nmcli connection modify "<connection>" 802-3-ethernet.wake-on-lan magic

Windows

Di BIOS/UEFI, aktifkan Wake on LAN (namanya bervariasi: Wake on LAN, Power On By PCI-E, Resume by PCI-E). Jika ada opsi ErP, EuP, atau deep sleep, matikan, karena opsi itu memutus daya kartu jaringan.

Buka Device Manager, klik dua kali adaptor jaringan Anda, tab Power Management: centang “Allow this device to wake the computer” dan “Only allow a magic packet to wake the computer”.

Di jendela yang sama, tab Advanced: atur “Wake on Magic Packet” ke Enabled (jika ada dalam daftar).

Matikan Fast Startup: Control Panel → Power Options → Choose what the power buttons do → Change settings that are currently unavailable → hapus centang “Turn on fast startup”. Saat Fast Startup aktif, PC yang sudah dimatikan sering mengabaikan paket ajaib.

macOS

Buka System Settings → Battery (MacBook) atau Energy (Mac desktop) → Options, lalu aktifkan “Wake for network access”. Membangunkan paling baik lewat Ethernet: di MacBook gunakan adaptor Ethernet USB-C atau Thunderbolt dan biarkan tersambung ke daya. Mac yang tidur di Wi-Fi sering mengabaikan paket ajaib.

Di Wi-Fi, matikan juga “Private Wi-Fi address” untuk jaringan Anda (System Settings → Wi-Fi → Details), jika tidak Mac akan mendapat alamat MAC yang berbeda. Pada daftar di bawah, “Ethernet Address” adalah alamat MAC tiap port.

Di WakeDeck, tambahkan perangkat dengan alamat MAC PC. Cari di sini:

Linux

ip -br link

Windows

ipconfig /all

macOS

networksetup -listallhardwareports

Alamat broadcast: alamat terakhir jaringan Anda, misalnya 192.168.1.255 untuk 192.168.1.x (nilai bawaan 255.255.255.255 juga berfungsi di jaringan yang sama). Port: 9.

2. Mematikan jarak jauh lewat SSH (opsional)

Ganti PASTE_KEY_LINE_FROM_APP dengan baris kunci yang ditampilkan di layar Kunci SSH WakeDeck.

Aplikasi masuk dengan kuncinya sendiri, bukan kata sandi. PC memerlukan server SSH, dan kunci publik aplikasi harus ditambahkan ke sana. Perintah di bawah sudah berisi kunci Anda.

Linux

Instal dan jalankan server SSH (contoh untuk Debian/Ubuntu):

sudo apt install openssh-server && sudo systemctl enable --now ssh

Di Fedora, Arch, atau SteamOS layanannya bernama sshd:

sudo systemctl enable --now sshd

Tambahkan kunci aplikasi ke pengguna Anda. Baris ini membatasi kunci hanya untuk perintah mematikan:

mkdir -p ~/.ssh && chmod 700 ~/.ssh && echo 'PASTE_KEY_LINE_FROM_APP' >> ~/.ssh/authorized_keys && chmod 600 ~/.ssh/authorized_keys

Izinkan mematikan tanpa kata sandi. Jalankan ini, lalu tambahkan baris di bawahnya (ganti youruser, dan periksa path dengan: which shutdown):

sudo visudo -f /etc/sudoers.d/wakedeck
youruser ALL=(ALL) NOPASSWD: /usr/bin/shutdown

Windows

Di PowerShell sebagai Administrator, instal dan jalankan OpenSSH Server:

Add-WindowsCapability -Online -Name OpenSSH.Server~~~~0.0.1.0; Start-Service sshd; Set-Service -Name sshd -StartupType Automatic

Akun administrator: tambahkan kunci dan kunci izin berkas (jika tidak, SSH mengabaikan berkasnya):

Add-Content -Force -Path "$env:ProgramData\ssh\administrators_authorized_keys" -Value 'PASTE_KEY_LINE_FROM_APP'
icacls.exe "$env:ProgramData\ssh\administrators_authorized_keys" /inheritance:r /grant "Administrators:F" /grant "SYSTEM:F"

Untuk akun biasa, letakkan baris kunci di C:\Users\NAMA\.ssh\authorized_keys.

Jika masih ditolak: periksa bahwa firewall mengizinkan port TCP 22 (fitur OpenSSH biasanya menambahkan aturannya), dan bahwa akun itu bukan akun Microsoft Entra ID, yang tidak dapat memakai kunci.

macOS

Aktifkan server SSH: System Settings → General → Sharing → Remote Login, dan izinkan pengguna Anda.

Tambahkan kunci aplikasi ke pengguna Anda. Baris ini membatasi kunci hanya untuk perintah mematikan:

mkdir -p ~/.ssh && chmod 700 ~/.ssh && echo 'PASTE_KEY_LINE_FROM_APP' >> ~/.ssh/authorized_keys && chmod 600 ~/.ssh/authorized_keys

Izinkan mematikan tanpa kata sandi. Jalankan ini, lalu tambahkan baris di bawahnya (ganti youruser):

sudo visudo -f /etc/sudoers.d/wakedeck
youruser ALL=(ALL) NOPASSWD: /sbin/shutdown

Di layar ubah perangkat, isi host (IP atau nama), pengguna SSH (nama akun PC Anda), dan port (22). Ketuk Matikan sekarang. Pada pertama kali, pastikan sidik jari yang tampil cocok dengan milik PC, lalu ketuk Percayai. Sidik jari PC:

Linux

ssh-keygen -lf /etc/ssh/ssh_host_ecdsa_key.pub

Windows

ssh-keygen -lf $env:ProgramData\ssh\ssh_host_ecdsa_key.pub

macOS

ssh-keygen -lf /etc/ssh/ssh_host_ecdsa_key.pub

“PC menolak kunci SSH”: kunci atau nama pengguna salah. “Tidak dapat terhubung”: PC mati, atau host, port, atau firewall salah. “PC membalas dengan galat”: di Linux atau macOS biasanya karena aturan sudoers. “Kunci SSH PC berubah”: PC diinstal ulang atau kunci SSH-nya dibuat ulang; percayai kunci baru hanya jika Anda memang menduganya.

3. Di luar rumah (VPN)

Dari luar jaringan rumah, Anda perlu jalan masuk terlebih dahulu, misalnya VPN WireGuard atau Tailscale. Paket ajaib adalah broadcast, dan banyak VPN tidak meneruskan broadcast. Masukkan alamat broadcast jaringan Anda (misalnya 192.168.1.255) di perangkat. Jika menyalakan dari jauh tetap tidak berhasil, solusi yang lazim adalah perangkat kecil yang selalu menyala di rumah dan mengirim paket untuk Anda (router dengan Wake-on-LAN, atau Raspberry Pi). Mematikan jarak jauh lewat SSH berfungsi melalui VPN selama alamat PC dapat dijangkau.

Masalah jarak jauh: “tidak ada koneksi jaringan atau VPN” berarti ponsel tidak punya rute ke alamat itu, jadi hubungkan VPN dulu. “Alamat broadcast tidak ditemukan” berarti nama atau alamat di perangkat tidak dapat diselesaikan. VPN juga bisa menerima paket tetapi tidak pernah mengirimkannya: aplikasi tidak dapat mengetahuinya, karena paket ajaib tidak punya balasan. Periksa apakah PC menyala, dan lihat statusnya di daftar.
