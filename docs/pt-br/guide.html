Guia de configuração

Guia de configuração do PC. Para ligar, use as configurações da seção 1. O desligamento remoto por SSH (seção 2) é opcional.

1. Wake-on-LAN (configurações do PC)

Um pacote mágico liga um PC desligado ou em suspensão, mas só se a placa de rede ainda tiver energia e estiver escutando. Use cabo de rede: o Wi-Fi raramente funciona para ligar.

Linux

Na BIOS/UEFI, ative Wake on LAN (os nomes variam: Wake on LAN, Power On By PCI-E, Resume by PCI-E). Se houver opção ErP, EuP ou deep sleep, desative, pois ela corta a energia da placa de rede.

Descubra o nome da interface de rede (por exemplo enp8s0):

ip -br link

Verifique a configuração Wake-on. Deve mostrar g:

sudo ethtool <iface> | grep Wake-on

Ative (volta ao padrão ao reiniciar):

sudo ethtool -s <iface> wol g

Para manter após reiniciar, com o NetworkManager (troque o nome da conexão, veja nmcli connection show):

sudo nmcli connection modify "<connection>" 802-3-ethernet.wake-on-lan magic

Windows

Na BIOS/UEFI, ative Wake on LAN (os nomes variam: Wake on LAN, Power On By PCI-E, Resume by PCI-E). Se houver opção ErP, EuP ou deep sleep, desative, pois ela corta a energia da placa de rede.

Abra o Gerenciador de Dispositivos, clique duas vezes no adaptador de rede, aba Gerenciamento de Energia: marque “Permitir que este dispositivo ative o computador” e “Permitir somente que um pacote mágico ative o computador”.

Na mesma janela, aba Avançado: defina “Wake on Magic Packet” como Habilitado (se estiver na lista).

Desative a Inicialização Rápida: Painel de Controle → Opções de Energia → Escolher a função dos botões de energia → Alterar configurações indisponíveis → desmarque “Ativar inicialização rápida”. Com ela ligada, um PC desligado costuma ignorar o pacote mágico.

macOS

Abra Ajustes do Sistema → Bateria (MacBook) ou Economia de Energia (Mac de mesa) → Opções e ative “Ativar para acesso à rede”. Ligar funciona melhor por cabo: no MacBook, use um adaptador Ethernet USB-C ou Thunderbolt e deixe na tomada. Um Mac em suspensão no Wi-Fi costuma ignorar o pacote mágico.

No Wi-Fi, desative também “Endereço Wi-Fi privado” da sua rede (Ajustes do Sistema → Wi-Fi → Detalhes), senão o Mac recebe outro endereço MAC. Na lista abaixo, “Ethernet Address” é o endereço MAC de cada porta.

No WakeDeck, adicione o dispositivo com o endereço MAC do PC. Para descobrir:

Linux

ip -br link

Windows

ipconfig /all

macOS

networksetup -listallhardwareports

Endereço de broadcast: o último endereço da sua rede, por exemplo 192.168.1.255 para 192.168.1.x (o padrão 255.255.255.255 também funciona na mesma rede). Porta: 9.

2. Desligamento remoto por SSH (opcional)

Troque PASTE_KEY_LINE_FROM_APP pela linha da chave mostrada na tela Chave SSH do WakeDeck.

O app entra com a própria chave, nunca com senha. O PC precisa de um servidor SSH e a chave pública do app precisa estar nele. Os comandos abaixo já contêm a sua chave.

Linux

Instale e inicie o servidor SSH (exemplo Debian/Ubuntu):

sudo apt install openssh-server && sudo systemctl enable --now ssh

No Fedora, Arch ou SteamOS o serviço se chama sshd:

sudo systemctl enable --now sshd

Adicione a chave do app ao seu usuário. A linha limita a chave ao comando de desligar:

mkdir -p ~/.ssh && chmod 700 ~/.ssh && echo 'PASTE_KEY_LINE_FROM_APP' >> ~/.ssh/authorized_keys && chmod 600 ~/.ssh/authorized_keys

Permita desligar sem senha. Execute isto e depois adicione a linha abaixo (troque youruser e confira o caminho com: which shutdown):

sudo visudo -f /etc/sudoers.d/wakedeck
youruser ALL=(ALL) NOPASSWD: /usr/bin/shutdown

Windows

No PowerShell como Administrador, instale e inicie o Servidor OpenSSH:

Add-WindowsCapability -Online -Name OpenSSH.Server~~~~0.0.1.0; Start-Service sshd; Set-Service -Name sshd -StartupType Automatic

Conta de administrador: adicione a chave e restrinja as permissões do arquivo (senão o SSH o ignora):

Add-Content -Force -Path "$env:ProgramData\ssh\administrators_authorized_keys" -Value 'PASTE_KEY_LINE_FROM_APP'
icacls.exe "$env:ProgramData\ssh\administrators_authorized_keys" /inheritance:r /grant "Administrators:F" /grant "SYSTEM:F"

Conta normal: coloque a linha da chave em C:\Users\NOME\.ssh\authorized_keys.

Se ainda recusar: veja se o firewall permite a porta TCP 22 (o recurso OpenSSH normalmente cria a regra) e se a conta não é uma conta Microsoft Entra ID, que não aceita chaves.

macOS

Ative o servidor SSH: Ajustes do Sistema → Geral → Compartilhamento → Login Remoto, e permita o seu usuário.

Adicione a chave do app ao seu usuário. A linha limita a chave ao comando de desligar:

mkdir -p ~/.ssh && chmod 700 ~/.ssh && echo 'PASTE_KEY_LINE_FROM_APP' >> ~/.ssh/authorized_keys && chmod 600 ~/.ssh/authorized_keys

Permita desligar sem senha. Execute isto e depois adicione a linha abaixo (troque youruser):

sudo visudo -f /etc/sudoers.d/wakedeck
youruser ALL=(ALL) NOPASSWD: /sbin/shutdown

Na tela de edição do dispositivo, preencha o host (IP ou nome), o usuário SSH (nome da sua conta no PC) e a porta (22). Toque em Desligar agora. Na primeira vez, confira se a impressão digital mostrada é a do PC e toque em Confiar. A impressão digital do PC:

Linux

ssh-keygen -lf /etc/ssh/ssh_host_ecdsa_key.pub

Windows

ssh-keygen -lf $env:ProgramData\ssh\ssh_host_ecdsa_key.pub

macOS

ssh-keygen -lf /etc/ssh/ssh_host_ecdsa_key.pub

“O PC recusou a chave SSH”: chave ou usuário errados. “Não foi possível conectar”: o PC está desligado, ou host, porta ou firewall estão errados. “O PC respondeu com um erro”: no Linux ou macOS costuma ser a regra do sudoers. “A chave SSH do PC mudou”: o PC foi reinstalado ou as chaves SSH foram recriadas; só confie na nova se já esperava isso.

3. Fora de casa (VPN)

De fora da sua rede é preciso primeiro um caminho até ela, por exemplo uma VPN WireGuard ou Tailscale. O pacote mágico é um broadcast, e muitas VPNs não repassam broadcasts. Coloque o endereço de broadcast da sua rede (por exemplo 192.168.1.255) no dispositivo. Se ainda não ligar à distância, o usual é um pequeno aparelho sempre ligado em casa que envia o pacote por você (um roteador com Wake-on-LAN ou um Raspberry Pi). O desligamento remoto por SSH funciona pela VPN desde que o endereço do PC seja alcançável.

Problemas à distância: “sem conexão de rede ou VPN” significa que o celular não tem rota para esse endereço, então conecte a VPN primeiro. “Endereço de broadcast não encontrado” significa que o nome ou endereço do dispositivo não pôde ser resolvido. Uma VPN também pode aceitar o pacote e nunca entregá-lo: o app não consegue saber, porque o pacote mágico não tem resposta. Confira se o PC liga e veja o status dele na lista.
