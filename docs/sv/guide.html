Installationsguiden

Installationsguide för datorn. För att starta behövs inställningarna i avsnitt 1. Fjärravstängning via SSH (avsnitt 2) är valfritt.

1. Wake-on-LAN (datorinställningar)

Ett magiskt paket väcker en dator som är avstängd eller i viloläge, men bara om nätverkskortet fortfarande har ström och lyssnar. Använd nätverkskabel: Wi-Fi fungerar sällan för väckning.

Linux

Aktivera Wake on LAN i BIOS/UEFI (namnen varierar: Wake on LAN, Power On By PCI-E, Resume by PCI-E). Om det finns ett ErP-, EuP- eller djupviloläge-alternativ ska du stänga av det, eftersom det kapar strömmen till nätverkskortet.

Ta reda på nätverksgränssnittets namn (till exempel enp8s0):

ip -br link

Kontrollera Wake-on-inställningen. Den måste visa g:

sudo ethtool <iface> | grep Wake-on

Slå på den (återställs vid omstart):

sudo ethtool -s <iface> wol g

För att behålla den efter omstarter med NetworkManager (ersätt anslutningens namn, se nmcli connection show):

sudo nmcli connection modify "<connection>" 802-3-ethernet.wake-on-lan magic

Windows

Aktivera Wake on LAN i BIOS/UEFI (namnen varierar: Wake on LAN, Power On By PCI-E, Resume by PCI-E). Om det finns ett ErP-, EuP- eller djupviloläge-alternativ ska du stänga av det, eftersom det kapar strömmen till nätverkskortet.

Öppna Enhetshanteraren, dubbelklicka på nätverkskortet, fliken Energisparfunktioner: markera ”Tillåt att enheten väcker datorn” och ”Tillåt endast magiska paket att väcka datorn”.

I samma fönster, fliken Avancerat: ställ in ”Wake on Magic Packet” på Enabled (om den finns i listan).

Stäng av Snabbstart: Kontrollpanelen → Energialternativ → Välj funktion för strömbrytarna → Ändra inställningar som för närvarande inte är tillgängliga → avmarkera ”Aktivera snabbstart”. Med Snabbstart på ignorerar en avstängd dator ofta det magiska paketet.

macOS

Öppna Systeminställningar → Batteri (MacBook) eller Energi (stationär Mac) → Alternativ och slå på ”Väck för nätverksåtkomst”. Väckning fungerar bäst över Ethernet: på en MacBook använder du en USB-C- eller Thunderbolt-Ethernetadapter och låter den vara ansluten till ström. En Mac i vila på Wi-Fi ignorerar ofta det magiska paketet.

På Wi-Fi ska du också stänga av ”Privat Wi-Fi-adress” för ditt nätverk (Systeminställningar → Wi-Fi → Detaljer), annars får Mac-datorn en annan MAC-adress. I listan nedan är ”Ethernet Address” varje ports MAC-adress.

Lägg till enheten i WakeDeck med datorns MAC-adress. Du hittar den här:

Linux

ip -br link

Windows

ipconfig /all

macOS

networksetup -listallhardwareports

Broadcast-adress: nätverkets sista adress, till exempel 192.168.1.255 för 192.168.1.x (standardvärdet 255.255.255.255 fungerar också i samma nätverk). Port: 9.

2. Fjärravstängning via SSH (valfritt)

Ersätt PASTE_KEY_LINE_FROM_APP med nyckelraden som visas på skärmen SSH-nyckel i WakeDeck.

Appen loggar in med sin egen nyckel, aldrig med lösenord. Datorn behöver en SSH-server, och appens publika nyckel måste läggas till på den. Kommandona nedan innehåller redan din nyckel.

Linux

Installera och starta SSH-servern (exemplet gäller Debian/Ubuntu):

sudo apt install openssh-server && sudo systemctl enable --now ssh

På Fedora, Arch eller SteamOS heter tjänsten i stället sshd:

sudo systemctl enable --now sshd

Lägg till appens nyckel för din användare. Raden begränsar nyckeln till avstängningskommandot:

mkdir -p ~/.ssh && chmod 700 ~/.ssh && echo 'PASTE_KEY_LINE_FROM_APP' >> ~/.ssh/authorized_keys && chmod 600 ~/.ssh/authorized_keys

Tillåt avstängning utan lösenord. Kör det här och lägg sedan till raden under (ersätt youruser och kontrollera sökvägen med: which shutdown):

sudo visudo -f /etc/sudoers.d/wakedeck
youruser ALL=(ALL) NOPASSWD: /usr/bin/shutdown

Windows

Installera och starta OpenSSH Server i PowerShell som administratör:

Add-WindowsCapability -Online -Name OpenSSH.Server~~~~0.0.1.0; Start-Service sshd; Set-Service -Name sshd -StartupType Automatic

Administratörskonto: lägg till nyckeln och lås filens behörigheter (annars ignorerar SSH filen):

Add-Content -Force -Path "$env:ProgramData\ssh\administrators_authorized_keys" -Value 'PASTE_KEY_LINE_FROM_APP'
icacls.exe "$env:ProgramData\ssh\administrators_authorized_keys" /inheritance:r /grant "Administrators:F" /grant "SYSTEM:F"

För ett vanligt konto lägger du i stället nyckelraden i C:\Users\NAMN\.ssh\authorized_keys.

Om den ändå nekar: kontrollera att brandväggen tillåter TCP-port 22 (OpenSSH-funktionen lägger normalt till regeln) och att kontot inte är ett Microsoft Entra ID-konto, som inte kan använda nycklar.

macOS

Slå på SSH-servern: Systeminställningar → Allmänt → Delning → Fjärrinloggning, och tillåt din användare.

Lägg till appens nyckel för din användare. Raden begränsar nyckeln till avstängningskommandot:

mkdir -p ~/.ssh && chmod 700 ~/.ssh && echo 'PASTE_KEY_LINE_FROM_APP' >> ~/.ssh/authorized_keys && chmod 600 ~/.ssh/authorized_keys

Tillåt avstängning utan lösenord. Kör det här och lägg sedan till raden under (ersätt youruser):

sudo visudo -f /etc/sudoers.d/wakedeck
youruser ALL=(ALL) NOPASSWD: /sbin/shutdown

På enhetens redigeringsskärm fyller du i värd (IP eller namn), SSH-användare (ditt kontonamn på datorn) och port (22). Tryck på Stäng av nu. Första gången ska du kontrollera att fingeravtrycket som visas stämmer med datorns och sedan trycka på Lita på. Datorns fingeravtryck:

Linux

ssh-keygen -lf /etc/ssh/ssh_host_ecdsa_key.pub

Windows

ssh-keygen -lf $env:ProgramData\ssh\ssh_host_ecdsa_key.pub

macOS

ssh-keygen -lf /etc/ssh/ssh_host_ecdsa_key.pub

”Datorn nekade SSH-nyckeln”: fel nyckel eller användarnamn. ”Det gick inte att ansluta”: datorn är avstängd, eller så är värd, port eller brandvägg fel. ”Datorn svarade med ett fel”: på Linux eller macOS är det oftast sudoers-regeln. ”Datorns SSH-nyckel har ändrats”: datorn har installerats om eller så har dess SSH-nycklar skapats på nytt; lita bara på den nya nyckeln om du väntade dig det.

3. Borta hemifrån (VPN)

Utanför ditt hemnätverk behöver du först en väg in, till exempel ett WireGuard- eller Tailscale-VPN. Ett magiskt paket är en broadcast, och många VPN vidarebefordrar inte broadcast. Ange nätverkets broadcast-adress (till exempel 192.168.1.255) i enheten. Fungerar väckning på distans ändå inte är den vanliga lösningen en liten enhet som alltid är på hemma och skickar paketet åt dig (en router med Wake-on-LAN eller en Raspberry Pi). Fjärravstängning via SSH fungerar över ett VPN så länge datorns adress går att nå.

Problem på distans: ”ingen nätverks- eller VPN-anslutning” betyder att telefonen saknar väg till adressen, så anslut VPN först. ”Broadcast-adressen hittades inte” betyder att namnet eller adressen i enheten inte går att slå upp. Ett VPN kan också ta emot paketet utan att någonsin leverera det: appen kan inte veta det, eftersom ett magiskt paket inte har något svar. Kontrollera att datorn startar och titta på dess status i listan.
