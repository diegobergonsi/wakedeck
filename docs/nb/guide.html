Oppsettguiden

Oppsettguide for PC-en. Det å slå på krever innstillingene i avsnitt 1. Fjernavslåing via SSH (avsnitt 2) er valgfritt.

1. Wake-on-LAN (PC-innstillinger)

En magisk pakke vekker en PC som er avslått eller i dvale, men bare hvis nettverkskortet fortsatt får strøm og lytter. Bruk nettverkskabel: Wi-Fi fungerer sjelden for oppvåkning.

Linux

Slå på Wake on LAN i BIOS/UEFI (navnene varierer: Wake on LAN, Power On By PCI-E, Resume by PCI-E). Hvis det finnes en ErP-, EuP- eller dyp dvale-innstilling, slår du den av, fordi den kutter strømmen til nettverkskortet.

Finn navnet på nettverksgrensesnittet (for eksempel enp8s0):

ip -br link

Sjekk Wake-on-innstillingen. Den skal vise g:

sudo ethtool <iface> | grep Wake-on

Slå den på (nullstilles ved omstart):

sudo ethtool -s <iface> wol g

Slik beholder du den etter omstart med NetworkManager (bytt ut tilkoblingens navn, se nmcli connection show):

sudo nmcli connection modify "<connection>" 802-3-ethernet.wake-on-lan magic

Windows

Slå på Wake on LAN i BIOS/UEFI (navnene varierer: Wake on LAN, Power On By PCI-E, Resume by PCI-E). Hvis det finnes en ErP-, EuP- eller dyp dvale-innstilling, slår du den av, fordi den kutter strømmen til nettverkskortet.

Åpne Enhetsbehandling, dobbeltklikk på nettverkskortet ditt, fanen Strømstyring: kryss av for «Tillat at denne enheten vekker datamaskinen» og «Tillat bare en magisk pakke å vekke datamaskinen».

I samme vindu, fanen Avansert: sett «Wake on Magic Packet» til Enabled (hvis den finnes i listen).

Slå av Hurtigstart: Kontrollpanel → Strømalternativer → Velg hva strømknappene gjør → Endre innstillinger som ikke er tilgjengelige for øyeblikket → fjern avkrysningen for «Slå på hurtigoppstart». Når Hurtigstart er på, ignorerer en PC som er slått av ofte den magiske pakken.

macOS

Åpne Systeminnstillinger → Batteri (MacBook) eller Energi (stasjonær Mac) → Valg, og slå på «Våkn for nettverkstilgang». Oppvåking fungerer best via Ethernet: på en MacBook bruker du en USB-C- eller Thunderbolt-Ethernet-adapter og lar den sitte i strøm. En sovende Mac på Wi-Fi ignorerer ofte den magiske pakken.

På Wi-Fi må du også slå av «Privat Wi-Fi-adresse» for nettverket ditt (Systeminnstillinger → Wi-Fi → Detaljer), ellers får Macen en annen MAC-adresse. I listen nedenfor er «Ethernet Address» MAC-adressen til hver port.

Legg til enheten i WakeDeck med PC-ens MAC-adresse. Du finner den her:

Linux

ip -br link

Windows

ipconfig /all

macOS

networksetup -listallhardwareports

Kringkastingsadresse: nettverkets siste adresse, for eksempel 192.168.1.255 for 192.168.1.x (standardverdien 255.255.255.255 fungerer også på samme nettverk). Port: 9.

2. Fjernavslåing via SSH (valgfritt)

Bytt ut PASTE_KEY_LINE_FROM_APP med nøkkellinjen som vises på skjermen SSH-nøkkel i WakeDeck.

Appen logger på med sin egen nøkkel, aldri med passord. PC-en må ha en SSH-server, og appens offentlige nøkkel må legges til på den. Kommandoene nedenfor inneholder allerede nøkkelen din.

Linux

Installer og start SSH-serveren (eksempelet gjelder Debian/Ubuntu):

sudo apt install openssh-server && sudo systemctl enable --now ssh

På Fedora, Arch eller SteamOS heter tjenesten sshd i stedet:

sudo systemctl enable --now sshd

Legg appens nøkkel til brukeren din. Linjen begrenser nøkkelen til avslåingskommandoen:

mkdir -p ~/.ssh && chmod 700 ~/.ssh && echo 'PASTE_KEY_LINE_FROM_APP' >> ~/.ssh/authorized_keys && chmod 600 ~/.ssh/authorized_keys

Tillat avslåing uten passord. Kjør denne, og legg deretter til linjen under den (bytt ut youruser, og sjekk stien med: which shutdown):

sudo visudo -f /etc/sudoers.d/wakedeck
youruser ALL=(ALL) NOPASSWD: /usr/bin/shutdown

Windows

Installer og start OpenSSH Server i PowerShell som administrator:

Add-WindowsCapability -Online -Name OpenSSH.Server~~~~0.0.1.0; Start-Service sshd; Set-Service -Name sshd -StartupType Automatic

Administratorkonto: legg til nøkkelen og lås filens tillatelser (ellers ignorerer SSH filen):

Add-Content -Force -Path "$env:ProgramData\ssh\administrators_authorized_keys" -Value 'PASTE_KEY_LINE_FROM_APP'
icacls.exe "$env:ProgramData\ssh\administrators_authorized_keys" /inheritance:r /grant "Administrators:F" /grant "SYSTEM:F"

På en vanlig konto legger du i stedet nøkkellinjen i C:\Users\NAVN\.ssh\authorized_keys.

Hvis den fortsatt avviser: sjekk at brannmuren tillater TCP-port 22 (OpenSSH-funksjonen legger vanligvis til regelen), og at kontoen ikke er en Microsoft Entra ID-konto, som ikke kan bruke nøkler.

macOS

Slå på SSH-serveren: Systeminnstillinger → Generelt → Deling → Ekstern pålogging, og tillat brukeren din.

Legg appens nøkkel til brukeren din. Linjen begrenser nøkkelen til avslåingskommandoen:

mkdir -p ~/.ssh && chmod 700 ~/.ssh && echo 'PASTE_KEY_LINE_FROM_APP' >> ~/.ssh/authorized_keys && chmod 600 ~/.ssh/authorized_keys

Tillat avslåing uten passord. Kjør denne, og legg deretter til linjen under den (bytt ut youruser):

sudo visudo -f /etc/sudoers.d/wakedeck
youruser ALL=(ALL) NOPASSWD: /sbin/shutdown

På redigeringsskjermen til enheten fyller du ut vert (IP eller navn), SSH-bruker (kontonavnet ditt på PC-en) og port (22). Trykk på Slå av nå. Første gang må du sjekke at fingeravtrykket som vises, stemmer med PC-ens, og deretter trykke på Stol på. PC-ens fingeravtrykk:

Linux

ssh-keygen -lf /etc/ssh/ssh_host_ecdsa_key.pub

Windows

ssh-keygen -lf $env:ProgramData\ssh\ssh_host_ecdsa_key.pub

macOS

ssh-keygen -lf /etc/ssh/ssh_host_ecdsa_key.pub

«PC-en avviste SSH-nøkkelen»: feil nøkkel eller brukernavn. «Kunne ikke koble til»: PC-en er avslått, eller vert, port eller brannmur er feil. «PC-en svarte med en feil»: på Linux eller macOS er det som regel sudoers-regelen. «PC-ens SSH-nøkkel er endret»: PC-en er installert på nytt, eller SSH-nøklene er laget på nytt; stol bare på den nye nøkkelen hvis du ventet det.

3. Borte fra hjemmet (VPN)

Utenfor hjemmenettverket må du først ha en vei inn, for eksempel et WireGuard- eller Tailscale-VPN. En magisk pakke er en kringkasting, og mange VPN-er videresender ikke kringkastinger. Angi nettverkets kringkastingsadresse (for eksempel 192.168.1.255) i enheten. Hvis oppvåking på avstand fortsatt ikke virker, er den vanlige løsningen en liten enhet som alltid er på hjemme og sender pakken for deg (en ruter med Wake-on-LAN eller en Raspberry Pi). Fjernavslåing via SSH fungerer over et VPN så lenge PC-ens adresse kan nås.

Problemer på avstand: «ingen nettverks- eller VPN-tilkobling» betyr at telefonen ikke har noen rute til adressen, så koble først til VPN. «Fant ikke kringkastingsadressen» betyr at navnet eller adressen i enheten ikke kan slås opp. Et VPN kan også ta imot pakken uten å levere den: appen kan ikke se det, fordi en magisk pakke ikke har noe svar. Sjekk om PC-en slår seg på, og se statusen i listen.
